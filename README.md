# Dayflow - Human Resource Management System

Dayflow is a polished front-end prototype for a role-based HRMS. It implements the core flows from the supplied product brief: an HR dashboard, attendance tracking, leave requests and approvals, team directory, payroll visibility, and editable employee profile.

## Run locally

No build step is needed. Open `index.html` in a modern browser, or serve the folder with any static web server.

## Included interactions

- Check in/out and start/end a break
- Submit, approve, reject, filter, and inspect leave requests
- Search the team directory
- Navigate responsive HRMS views
- Edit and save profile data (prototype feedback)

This is an interactive prototype using in-browser demo data; no authentication or server-side persistence is configured yet.
