# Supabase workspace — Laptop 3

Laptop 3 owns migrations, seed data, local Supabase configuration, database
functions, and Row Level Security implementation in this directory.

Before adding SQL, read DATABASE_SCHEMA.md and API_CONTRACT.md. The foundation
contains no migration because database/business-logic ownership begins with
Laptop 3. Schema changes require matching documentation, generated TypeScript
types, a CHANGELOG.md entry, and Laptop 1 integration review.
